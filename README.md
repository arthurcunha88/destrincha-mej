# DMEJ — Destrincha MEJ

Portal editorial independente para quem já participa do Movimento Empresa Júnior e quer entender a Rede, desenvolver pessoas e melhorar a gestão da sua EJ.

O conteúdo reúne uma linha do tempo, fundamentos, referências do MEJ baiano, um acervo pesquisável e exercícios de aplicação. A interface e o conteúdo editorial estão disponíveis em português, inglês, francês e espanhol. Os materiais externos mantêm seu idioma e suas condições de acesso originais.

## Desenvolvimento e publicação

Use Node.js 24. Execute `npm run dev` para abrir a prévia local e `npm run build` para gerar o site em `dist/`. Também é possível executar `node build.ts --serve` e `node build.ts` diretamente. O projeto não tem dependências externas de compilação.

Na Vercel, importe este repositório. A configuração versionada gera e publica as páginas estáticas em `dist/`.
